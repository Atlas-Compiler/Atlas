# Go Basic Compilation Example

This example demonstrates how to compile web pages into clean markdown using the official Atlas Go SDK (`go.atlas-compiler.com/sdk`).

## Prerequisites

- Go 1.22+
- Atlas API Key (`export ATLAS_API_KEY="atlas_..."`)

## Run

```bash
go run main.go
# Or compile a specific URL:
go run main.go https://example.com
```
